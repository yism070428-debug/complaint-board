# 📢 종합 다중게시판 시스템 (CMS Master Board)

회원가입 없이 누구나 익명으로 접수할 수 있는 **VOC 신문고**부터 **자유게시판, 포토 갤러리, 공지사항**까지 한 번에 운영할 수 있는 종합 다중게시판 시스템입니다.

---

## 🚀 주요 탑재 기능

### 1. 🗂️ 다중 게시판 마스터 관리
- **동적 게시판 생성/수정/삭제**: 관리자 화면에서 ID(slug), 게시판 이름, 설명, 게시판 유형(목록형, 갤러리형, 웹진형, 공지형)을 자유롭게 생성 및 관리
- **상단 탭 실시간 연동**: 생성된 게시판들이 상단 폴더 탭으로 자동 노출

### 2. 👁️ 3가지 뷰(View) 모드 즉시 전환
- **목록형 (LIST)**: 2000년대 특유의 12px 돋움체, 점선 보더, 가독성 높은 클래식 테이블 뷰
- **갤러리형 (GALLERY)**: 첨부된 첫 번째 이미지를 썸네일 카드로 렌더링하는 포토 뷰
- **웹진형 (WEBZINE)**: 썸네일과 본문 요약문(Snippet), 작성 메타정보를 카드 리스트로 나열하는 요약 뷰

### 3. 💬 다중 댓글 및 1단계 대댓글 (답글)
- 누구나 자유롭게 댓글 및 대댓글(답글) 작성 가능
- **하이브리드 지원**: 비회원은 4자리 비밀번호로 작성 및 개별 삭제, 회원은 자동 로그인 닉네임 반영
- 관리자 공식 답변(RE)은 핑크색 뱃지와 함께 최상단 답변 박스로 동시 연동

### 4. 📎 파일 및 사진 첨부 (Zero-Dependency)
- 외부 모듈 없이 `multipart/form-data` 파서 내장
- 이미지(JPG, PNG, GIF) 및 문서 파일 업로드 및 게시글 상세 화면에서 즉시 다운로드

### 5. 👍 추천 / 비추천 (Vote System)
- 추천 및 비추천 투표 기능
- 동일 IP 기준 중복 투표 자동 방지

### 6. 👤 하이브리드 회원제 & 권한 시스템
- **익명(비회원) + 일반 회원 공존**:
  - 비회원: 4자리 비밀번호 기반 글 작성/수정/삭제
  - 회원: 아이디/비밀번호 간편 가입, 회원 등급(Level 1~9), 가입 축하 및 작성 포인트 적립
- 본인 글은 로그인 시 비밀번호 입력 없이 즉시 수정/삭제 가능

### 7. 🛡️ 관리자 운영 센터 (`/admin`)
- **게시글 일괄 관리**: 체크박스로 여러 글을 선택하여 **일괄 삭제** 또는 **타 게시판으로 일괄 이동**
- **휴지통 및 복원 (Soft Delete)**: 삭제된 글은 휴지통으로 이동하며, 관리자가 1클릭 복원 또는 영구 삭제 가능
- **금칙어(비속어) 자동 필터링**: 등록된 금칙어는 글/댓글 등록 시 자동으로 `***` 치환
- **회원 관리**: 가입된 회원 목록, 등급(Level) 및 포인트 조회/수정
- **공식 답변 & 상태 변경**: 접수대기 ➔ 검토중 ➔ 답변완료 ➔ 보류 상태 전이

## 💻 실행 방법

### 서버 즉시 실행 (데이터 자동 영구 보존)
```bash
node server.js
# 또는
npm start
```
> **데이터 영구 보존(Persistence) 안내:**  
> - 서버를 껐다 켜거나 재부팅하더라도 작성하신 모든 게시글/댓글/첨부파일은 `data/board.sqlite`에 안전하게 영구 저장됩니다.  
> - 처음 실행 시 기본 게시판 및 계정이 자동으로 준비되므로 별도의 시드 실행이 필요하지 않습니다.  
> - 만약 테스트 데이터로 완전 초기화를 원하실 때만 `node scripts/seed.js --force`를 입력하세요.

- **메인 게시판**: [http://localhost:3000](http://localhost:3000)
- **게시글 작성**: [http://localhost:3000/write](http://localhost:3000/write)
- **통합 관리자 센터**: [http://localhost:3000/admin](http://localhost:3000/admin) (`admin / admin1234!`)
- **테스트용 샘플 회원**: `user1 / user1234!`
